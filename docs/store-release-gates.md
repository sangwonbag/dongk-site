# 동경바닥재 App Store / Google Play 출시 점검

- 공통: 기존 Supabase 상품/가격/주문/로그인/관리자 화면 재사용. 별도 상품 DB 또는 앱 전용 결제창 없음
- 결제: 실제 배송되는 물리적 바닥재/벽지는 Apple 인앱 결제 대신 계좌이체/방문결제 등 외부 결제 수단 이용 가능 (Apple 3.1.3(e))
- Android: API 36 이상으로 빌드, 서명된 `.aab` 생성, Play Console 데이터보안/광고/콘텐츠등급/테스터 설정 완료
- Apple: Apple Developer Program, Xcode 코드 서명, App Store Connect, TestFlight, 실사용 화면 이미지 및 완전한 메타데이터
- 계정 생성 앱 필수: iOS 인앱 계정 삭제 시작 및 Google 인앱·외부 삭제 신청 URL; 개인정보 보관/제거 방침과 실제 서버 삭제 흐름 점검
- 기기 실검증: 웹뷰 카카오/기타 OAuth, 비밀번호 재설정, 우편번호 검색, 주문·입금 처리, 파일 공유/다운로드, 고객/관리자 권한, 네트워크 오류, 앱 뒤로가기
- 스토어 심사: Apple 4.2 최소 기능 규정상 원격 웹뷰만으로 승인 보장 불가. 실제 앱다운 차별적 기능과 지속적인 효용 평가
- 데모 계정: 실제 고객 주문이 접수되지 않는 심사용 테스트 계정 사용
- 인증/서명: 서명 키 및 개인정보를 GitHub에 업로드하지 말 것. 스토어 콘솔에서 직접 설정
- 순서: 검증된 개발 PR 배포 → 회원탈퇴/개인정보 보완 → 실기기 테스트 → AAB/IPA 서명·TestFlight/비공개 테스트 → 심사 → 공개
